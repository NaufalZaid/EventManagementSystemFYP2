# EventManagementSystemFYP2

## Project Title
Event Management System with Automated Scheduling Optimization Using Genetic Algorithms

## Description
A Laravel-based Final Year Project for managing events, venues, timeslots, and schedules, with future support for automated schedule generation using a genetic algorithm.

## Current Tech Stack
- Backend: Laravel
- Frontend: Blade
- Database: MySQL
- Language: PHP

## Current Modules
- Authentication
- Event Management
- Venue Management
- Timeslot Management
- Schedule Management
- Basic Conflict Validation

## Planned Intelligent Module
- Genetic Algorithm for schedule optimization

## Current Database Entities
- Users
- Events
- Venues
- Timeslots
- Event Schedules

## Current Progress
- Laravel project setup completed
- MySQL connection configured
- Event CRUD completed
- Venue CRUD completed
- Timeslot CRUD completed
- Schedule CRUD completed
- Basic scheduling conflict checks implemented

## Future Enhancements
- Overlapping time conflict detection
- Capacity constraint validation
- Automated schedule generation using genetic algorithms
- Fitness evaluation and schedule scoring
- Reporting and analytics dashboard
